Blue = negative offset, gray = zero, orange = positive. Colors on the right visualize signed values, not the actual encoding of a stored texture. Values are rounded for display.

Why this works

Remapping from input 0–1 to output A–B uses output = input × (B − A) + A.

For −0.1 to +0.1, this becomes output = input × 0.2 − 0.1. Midgray (0.5) becomes zero offset.

For a two-channel UV displacement texture, apply this calculation independently to R and G, then add the resulting offsets to U and V. Note that negative values require a signed-capable representation such as floating point; an ordinary normalized 8-bit texture cannot directly store negative values.
